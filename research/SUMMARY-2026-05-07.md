## Honest caveats

1. **Voter-file phone lever is largely exhausted after CO+AR.** The next phone-source dollar should fund **Numverify / Cloudmersive / Apollo** (already wired in `orchestrator.ts`) — not more voter files.

2. **Tier 6 brief was partially mis-framed.** Mechanic's liens in all 50 states are **recorded instruments at county recorders**, not trial-court filings. Trial-court adapters only catch the ~5-15% that escalate to foreclosure. **Recommend re-pointing Tier 6 work to county-recorder bulk feeds first** (same architecture as Tier 4 Phase 3 homestead adapters — build once, reuse twice).

3. **OpenGov ViewPoint conflict.** The Tier 2 agent recommends building the adapter; CLAUDE.md (per `docs/permit-catalog/opengov-viewpoint-partnership-2026-05-07.md`) says ToS prohibits automated extraction and the partnership path is preferred post-MRR. **The user must reconcile this** before any work proceeds. Recommend partnership.

4. **CA + WA parcel privacy walls are statutory, not technical.** AB1785 (CA) and the WA opt-out are not bypass-able by adding more counties. Henri's reachable parcel ceiling in those two states is permanently lower than the rest of the country.

5. **License-roster `field_map` values are best-guesses.** The Tier 3 agent's SQL block uses field-mapping conventions inferred from each state's published schema docs, but real-world Socrata datasets sometimes ship `licenseNumber` vs `license_no` vs `LIC_NUM` etc. **Recommend adding a `dry_run` flag to `state-licenses-rotate` before applying the migration** so the first sync prints the column-name diff instead of failing the cron.

6. **WebFetch hit walls on ~30% of probes** (state SOS WAFs, Cloudflare, SSL). Where the agents fell back to Google search-result excerpts, the report flags it. The user should eyeball-verify any URL marked "verified via search excerpt" before writing an ingestor against it.
