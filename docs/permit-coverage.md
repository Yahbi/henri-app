# US Building Permit Data Sources - State by State Summary

## Overview
This document provides a realistic assessment of building permit data availability across all US states. Based on comprehensive research of federal, state, county, and city-level sources.

**Last Updated:** March 17, 2026

---

## FEDERAL SOURCES (National Coverage)

### 1. US Census Bureau Building Permits Survey
- **Coverage:** All states, counties, CBSAs, and ~20,100 permit-issuing places
- **URL:** https://www.census.gov/construction/bps/
- **Format:** CSV, Excel
- **Access:** Direct download
- **Data Since:** 1980
- **Update Frequency:** Monthly (17th workday) and Annual (May 1)

### 2. HUD SOCDS Building Permits Database
- **Coverage:** All states, counties, CBSAs, and ~20,000 jurisdictions
- **URL:** https://www.huduser.gov/portal/portal_datasets.html
- **Format:** CSV, Excel, Interactive dashboard
- **Access:** Query tool + bulk download
- **Data Since:** 1980
- **Note:** Uses Census BPS data with enhanced interface

### 3. Data.gov
- **Coverage:** Federal datasets including HUD permits
- **URL:** https://catalog.data.gov/dataset/?tags=building-permits
- **Format:** CSV, JSON, REST API
- **Access:** API + Download

## KEY FINDINGS

### What EXISTS:
1. **Federal Coverage:** Census BPS and HUD SOCDS provide national coverage at aggregate levels (state, county, CBSA)
2. **Major Cities:** ~30-40 major US cities have functional open data APIs for building permits
3. **Platform Concentration:** Most available data is on Socrata, CKAN, or ArcGIS platforms
4. **State Portals:** Most states have open data portals but few include building permit data

### What DOESN'T EXIST:
1. **County Coverage:** Very few counties (maybe 5-10 nationwide) offer open building permit data
2. **Medium/Small Cities:** <5% of cities under 200,000 population have open permit data
3. **Standardized Formats:** Each jurisdiction uses different data schemas
4. **Historical Data:** Many portals only have recent years (2-5 years) of data
5. **Real-time Updates:** Many datasets updated monthly or quarterly, not real-time

### Access Reality:
- **Direct API Access:** ~45 jurisdictions
- **CSV Download:** ~15 jurisdictions  
- **Scrapable Web:** ~20 jurisdictions
- **FOIA/Request Required:** ~50 jurisdictions
- **No Public Access:** ~350+ jurisdictions

### Commercial Alternatives:
Many jurisdictions that don't offer open data sell permit data to commercial aggregators like:
- Reed Construction Data (RSMeans)
- Dodge Data & Analytics
- Buildfax
- ATTOM Data Solutions
- CoreLogic

## RECOMMENDATIONS

### For National Coverage:
1. **Start with Census BPS** - Only truly national source
2. **Use HUD SOCDS** - Better interface for same data
3. **Target the 45 cities with APIs** for detailed analysis
4. **Scrape the 20 web portals** for additional coverage

### For Specific States:
1. **Focus on states with multiple sources** (CA, TX, FL, NY)
2. **Combine federal + state + county + city data** where possible
3. **Use FOIA requests** for critical missing jurisdictions

### Data Quality Notes:
1. **Census data includes imputed values** for non-reporting jurisdictions
2. **City data varies in completeness** (some only residential, some all permits)
3. **Geocoding quality varies** - not all permits have lat/lon
4. **Update frequency varies** - daily to annual
